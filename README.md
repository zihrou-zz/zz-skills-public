# 公開共用 Skills

內部共用、且確認不含客戶資料與系統憑證的 Skill 放這裡。
含 app_id、資料庫操作、金流設定的 Skill 一律留在私有庫，不要搬進來。

## 目前收錄

| Skill | 用途 |
|---|---|
| [rd-ready-requirements](rd-ready-requirements/) | 把口頭需求收斂成 RD 直接能開工的開發需求書 |
| [news-article-image-production](news-article-image-production/) | 從新聞稿缺圖盤點到寫實情境配圖生成與逐張品質驗收 |

## 怎麼用

跟你的 AI 說：

> 去 github.com/zihrou-zz/zz-skills-public 找 rd-ready-requirements，照它的流程訪談我，產出一份 RD 需求書

或：

> 去 github.com/zihrou-zz/zz-skills-public 找 news-article-image-production，讀完文章後盤點缺圖，從零生成可信的新聞情境配圖

然後把手上有的東西全丟給它（會議記錄、截圖、舊文件、現有畫面）。

## 怎麼一起優化

1. **回饋的裁判是實際收件人，不是需求方。** 交付後請收件人回三行：看完還要問什麼／哪一段看不懂／使用時卡在哪。
2. 回饋開 issue，或直接改內容發 PR。要 push 權限跟 ZZ 要。
3. 改完請在 [CHANGELOG.md](CHANGELOG.md) 補一行。

⚠️ **回饋請去識別**：寫「某客戶」「某金額級距」，不要寫客戶名、真實金額、同事姓名。這是公開庫。
